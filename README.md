# 오늘의 밥 — 날씨 맞춤 점심 추천

현재 위치의 날씨에 맞는 점심 메뉴 5개를 추천하고, 근처 식당을 카카오맵으로 찾아 주는 웹앱입니다.
서버 없이 브라우저에서만 동작합니다. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 카카오 키 넣기

`config.js`에 **공용 카카오 앱("내 웹앱 공용")의 JavaScript 키**를 붙여넣으면 끝입니다.

```js
window.APP_CONFIG = { KAKAO_JS_KEY: "여기에_JavaScript_키" };
```

공용 앱을 만드는 방법, 도메인 등록, 무료로 계속 쓰는 방법은 [카카오맵_공용설정_가이드.md](카카오맵_공용설정_가이드.md)에 있습니다.
키가 없어도 날씨와 메뉴 추천은 동작합니다. 이때는 식당 수와 식당 목록만 빠집니다.

## GitHub Pages로 올리기

1. GitHub에 공개 저장소 `lunch-app`을 만듭니다.
2. GitHub Desktop에서 이 폴더를 열고 **Publish repository**를 누릅니다. 이후 수정할 때는 **Push origin**을 누릅니다.
3. GitHub 저장소 → Settings → Pages → Branch를 `main` / `(root)`로 정하고 저장합니다.
4. 1~2분 뒤 https://chansi008-prog.github.io/lunch-app/ 에서 열립니다.

## 홈 화면에 추가

- **아이폰(사파리):** 공유 버튼 → 홈 화면에 추가
- **안드로이드(크롬):** 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치

## 메뉴 고치기

추천 메뉴는 `menus.js`에 모여 있습니다. 메뉴 이름이 그대로 카카오 검색어가 됩니다.
검색어가 달라야 하면 `q`를 적습니다. 예: `{ name: "찌개류", q: "찌개", conds: ["cold"] }`

## 업데이트할 때

파일을 고친 뒤 `sw.js`의 `VERSION`(예: `lunch-v1` → `lunch-v2`)을 올려야 폰에도 새 버전이 반영됩니다.

## 문제가 생기면

- **"오늘 검색 한도에 도달했어요"가 계속 나옴:** 카카오 공용 앱의 사이트 도메인에 `https://chansi008-prog.github.io`가 등록돼 있는지, 카카오맵 사용 설정이 ON인지 확인하세요. 키가 틀렸거나 도메인이 빠져 있어도 같은 안내가 나옵니다.
- **위치가 안 잡힘:** 폰 설정에서 브라우저의 위치 권한을 확인하세요. 권한이 없어도 지역 이름(예: 판교역)을 입력해서 쓸 수 있습니다.
